# 🧩 لعبة تركيب الصور الاحترافية (Professional Picture Puzzle Game)

لعبة تفاعلية ممتعة ومتجاوبة لتركيب الصور (Puzzle Game)، مبنية باستخدام تقنيات الويب الحديثة (HTML5, CSS3, JavaScript) وتعمل بكفاءة عالية على الهواتف الذكية وأجهزة سطح المكتب.

---

## ✨ المميزات الرئيسية

- **تصميم متجاوب بالكامل (Responsive):** مصممة لتناسب مختلف مقاسات الشاشات والهواتف المحمولة.
- **نظام المراحل التدريجي:** تحتوي على **10 مراحل** مشوقة، حيث تكون المراحل التالية مقفلة حتى يتم إنهاء المرحلة الحالية بنجاح.
- **حفظ التقدم (LocalStorage):** يتم حفظ النقاط والمراحل المفتوحة تلقائياً في متصفح المستخدم لضمان عدم ضياع التقدم عند إغلاق الصفحة.
- **آلية لعب سلسة:** تعتمد على التبديل البصري المباشر بين قطع اللغز (شبكة 3x3) مع زر فحص الحل اليدوي لضمان تجربة مستخدم سلسة وخالية من الأخطاء.
- **واجهة عصرية:** مدعومة بمكتبة Bootstrap 5 وأيقونات FontAwesome وتصميم أنيق يدعم اللغة العربية (RTL).

---

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3** (Grid & Flexbox Layouts)
- **Vanilla JavaScript (ES6+)** دون الحاجة لأي مكتبات برمجية خارجية معقدة.
- **Bootstrap 5** للتنسيق العام وتصميم الواجهات.
- **FontAwesome** للأيقونات التفاعلية.
- **Web Storage API (LocalStorage)** لإدارة حالة اللعبة والنقاط.
